# UI Design System

# Purpose

The UI Design System ensures every screen in AgriNova AI follows the same visual language. It provides reusable design rules, components, colors, typography, spacing, and animations to maintain consistency across the application.

# 1. Design Philosophy

AgriNova AI combines **Nature** and **Artificial Intelligence** into a clean, premium interface.

Design Inspiration:

- Apple
- Linear
- Nothing OS
- Raycast
- Tesla Dashboard

The interface should feel:

- Modern
- Minimal
- Calm
- Professional
- Easy to use

---

# 2. Design Principles

Every screen should follow these principles.

- Consistent
- Minimal
- Reusable
- Responsive
- Accessible
- Performance Friendly

Avoid unnecessary visual clutter.

---

# 3. Color Palette

| Color | Usage |
|--------|-------|
| #010603 | Main Background |
| #07140A | Surface |
| #0B1B10 | Cards |
| #66FF88 | Primary Accent |
| #4FAE68 | Secondary Accent |
| #55F6FF | Information |
| #FFC857 | Warning |
| #FF6B6B | Error |
| #FFFFFF | Primary Text |
| #B8C4BC | Secondary Text |

Green is reserved for AI insights, success states, and primary actions.

# 4. Typography

| Font | Usage |

Typography hierarchy:

- Title
- Heading
- Subtitle
- Body
- Caption
- Label

---

# 5. Spacing System

Use a consistent spacing scale.

| Size | Value |
|------|------|
| XS | 4px |
| SM | 8px |
| MD | 16px |
| LG | 24px |
| XL | 32px |
| XXL | 48px |

Avoid arbitrary spacing values.

# 8. Icons & Images

Icons should be:

- Simple
- Consistent
- Outline Style
- Easy to recognize

Images should be:

- Optimized
- Responsive
- High Quality

Use meaningful illustrations instead of decorative graphics.

---

# 9. Animation System

Animations improve user experience without distracting users.

Common animations:

- Fade In
- Slide Up
- Hover Lift
- Ripple
- Logo Float
- Aura Pulse
- Page Transition

Animations should remain smooth and subtle.

---

# 10. Responsive Design

Supported devices:

- Desktop
- Laptop
- Tablet
- Mobile

Responsive rules:

- Flexible grids
- Adaptive navigation
- Touch-friendly controls
- Consistent spacing
- Responsive typography

---

# 11. Accessibility

UI should support:

- Keyboard Navigation
- Screen Readers
- Semantic HTML
- Sufficient Color Contrast
- Accessible Forms
- Focus Indicators

Accessibility should be considered during development rather than added later.

---

# 12. Summary

The AgriNova AI UI Design System provides a unified design language for the entire application. By using shared colors, typography, spacing, reusable components, and consistent layouts, every screen maintains a professional, scalable, and user-friendly experience.
